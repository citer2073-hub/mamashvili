# Запуск проекта локально

## 1. Установка
```bash
npm install
```

## 2. Локальный запуск
```bash
npm run dev
```

## 3. Сборка
```bash
npm run build
```

## 4. Firebase Hosting
```bash
firebase login
firebase use --add
firebase deploy
```

## Что важно
- Исходный файл сохранён без изменений в `original/App (1).tsx`.
- Рабочая копия для проекта лежит в `src/App.tsx`.
- Firebase Hosting настроен на папку `dist`.
